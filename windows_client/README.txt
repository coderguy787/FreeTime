FreeTime - Windows Secure Chat Client
=======================================

A full-featured Windows desktop secure chat application ported from the FreeTime Android app.

Features:
- End-to-end encrypted messaging
- Two-factor authentication (TOTP)
- Friend system with requests
- 1-on-1 chat with message history
- Group chat with member management
- Channels (announcement-only, admin post, read-only for members)
- File and media sharing
- Voice and video calls (WebRTC)
- Delete history with voting system
- Message pinning in channels
- Real-time WebSocket messaging
- Dark theme (Black/Magenta/Light Grey)

Requirements:
- Python 3.10+
- Windows 10/11

Setup:
  pip install -r requirements.txt

Run:
  python run.py

Build EXE:
  build.bat
